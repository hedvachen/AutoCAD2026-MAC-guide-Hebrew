מה זה AutoCAD 2026?
מבוא לתוכנה ולגרסה האחרונה
AutoCAD — תוכנת השרטוט המקצועית של Autodesk
AutoCAD היא תוכנת ה-CAD (Computer-Aided Design) המובילה בעולם, המיוצרת על-ידי Autodesk מאז 1982. גרסת 2026 ממשיכה את המסורת של שרטוט דיוק גבוה לתחומי אדריכלות, הנדסה אזרחית, מכונות, עיצוב פנים ועוד.
🎯 שרטוט 2D

קווים, קשתות, עיגולים, מצולעים, ומעגלים בדיוק מוחלט באמצעות קואורדינטות ופקודות.

📐 מידות מדויקות

כל אובייקט מבוסס על מספרים מדויקים — לא שרטוט חופשי. כל קו יכול להיות בדיוק 5.75 מטר.

🍎 תמיכה במק

AutoCAD 2026 פועל ב-macOS Ventura ו-Sonoma באופן מלא, כולל תמיכת Apple Silicon (M1–M4).

ניתן לעבוד גם דרך הדפדפן בכל מחשב ב-web.autocad.com ובאפליקציית Mobile.

שכבות (Layers) הן כמו שקפים שקופים שמוחלים זה על גבי זה. כל Layer יכול להיות בצבע, קו ועובי שונה, ואפשר להסתיר, לנעול, או להדפיס אותו בנפרד. זהו כלי ארגון בסיסי בכל שרטוט מקצועי.

לחץ Grip + Shiftבחר מספר Grips בו-זמנית

קבצי CTB — Plot Style Tables
ניהול צבעים, עובי קווים וסגנון הדפסה
מה זה CTB ולמה זה חשוב?
קובץ CTB (Color-dependent plot style Table) הוא קובץ הגדרות שמכתיב לאוטוקאד כיצד להדפיס כל צבע. בשרטוט שלך, קו אדום (Color 1) הוא לא בהכרח אדום בהדפסה — ה-CTB מחליט שהוא ידפס בשחור עם עובי 0.25mm. ה-CTB מאפשר לנתק בין צבע השרטוט לצבע ועובי ההדפסה.

🔑 הקשר: צבע שכבה → CTB → פלט מדפסת

כל שכבה (Layer) מוגדרת עם צבע (Color 1=אדום, Color 2=צהוב...). ה-CTB מגדיר לכל צבע:

  • Color: שחור / לבן / אפור / צבע מקורי (Use Object Color)
  • Lineweight: עובי הקו בהדפסה — 0.13mm, 0.18mm, 0.25mm, 0.35mm, 0.50mm...
  • Linetype: סוג קו בהדפסה (בד"כ Use Object Linetype)
  • Screening: אחוז כיסוי דיו — 100% = מלא, 50% = אפור בהיר
📄 CTB — Color-Dependent

כל צבע AutoCAD (1-255) מוגדר בנפרד. הנפוץ ביותר. monochrome.ctb הוא CTB.

📋 STB — Named Style

סגנון לפי שם — לא לפי צבע. פחות נפוץ. מאפשר אובייקטים מאותו צבע להדפיס שונה.

💡
CTB או STB? ב-99% מהמקרים עובדים עם CTB. STB נמצא בשימוש בארגונים עם תקן הדפסה מורכב. הגדרות ב-OPTIONS ← Plot and Publish ← Default plot style behavior.

הגדרת CTB צעד אחר צעד — ממש כמו Windows
כך עורכים כל צבע ב-CTB — בדיוק כמו ב-Windows, רק ממשק Mac:
פתח עורך CTB: STYLESMANAGER ← לחץ כפול על קובץ CTB (לדוגמה monochrome.ctb) ← נפתח Plot Style Table Editor
בחר צבע לעריכה: בעמודת "Plot styles" בחר Color_1 (= שכבות עם Color 1 אדום).
Color_1 = אדום, Color_2 = צהוב, Color_3 = ירוק, Color_4 = ציאן, Color_5 = כחול, Color_6 = מגנטה, Color_7 = לבן/שחור
שנה צבע הדפסה: "Color" ← בחר Black (שחור) לתכניות B&W.
או בחר Use Object Color לשמירת הצבע המקורי (להדפסת צבע).
הגדר עובי קו (Lineweight): לחץ על "Lineweight" ← פתח רשימה ← בחר עובי הרצוי.
עוביים נפוצים לפי שימוש:
0.13mm — קווי עזר, ציר, מרקם
0.18mm — קווים דקים, מידות, טקסט קטן
0.25mm — קווים רגילים, קירות פנים
0.35mm — קירות חיצוניים, גבולות
0.50mm — קווי גוש ראשיים, מסגרת

  • השתמש ב-OSNAP תמיד. שרטוט ללא OSNAP = חיבורים לא מדויקים = בעיות בעתיד.
  • שמור לעתים קרובות. ⌘+S כל 5–10 דקות. AutoCAD יכול להתקפא.
  • השתמש בשכבות באופן עקבי. כל "סוג" של אובייקט = שכבה משלו.
  • Space Bar = Enter. מהיר יותר מהגעה ל-Enter. חזרה על פקודה אחרונה.
  • ByLayer לצבע, Linetype ו-Lineweight. אל תגדיר אלה ישירות על אובייקטים — שנה את הגדרות השכבה.
  • PURGE לפני שמירה סופית. מנקה הגדרות לא בשימוש ומקטין קובץ.
  • ESC מיד לאחר שגמרת. אל תשאיר פקודה פעילה — זה גורם לטעויות.
  • Zoom Extents בסיום. Z → E לראות את כל השרטוט לפני הדפסה.
  • גיבוי! DWG שמור כ-BAK אחד בלבד. שמור גיבויים ידניים בתיקיות ממוספרות.
⚡ טיפ מהירות 1

לאחר TRIM, לחץ Enter (ריק) ← מייד תוכל לגזור מכל האובייקטים. ל-90% מהשימושים זה מספיק!

⚡ טיפ מהירות 2

בחר אובייקט ← ⌘+C ← ⌘+V — ה-Paste יהיה "בהמשך", לא בנקודת ה-Copy המקורית. השתמש ב-COPYBASE לדיוק.

⚡ טיפ מהירות 3

Shift + TRIM = EXTEND. Shift + EXTEND = TRIM. לא צריך לצאת ולהיכנס מחדש!

⚡ טיפ מהירות 4

לחץ 2× על Grip כחול ← מעבר מ-STRETCH ל-ROTATE ל-SCALE בלי פקודה.

⚡ טיפ מהירות 5

ב-COPY/MOVE: הקלד @0,0 ← העתק בדיוק על אותו מיקום (לשינוי שכבה).

⚡ טיפ מהירות 6

OOPS = ביטול מחיקה אחרונה בלבד (גם אחרי פקודות אחרות, שלא כמו UNDO).
